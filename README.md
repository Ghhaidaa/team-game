# مسابقة الفرق — لعبة جماعية مباشرة (QR + جوالات + لاعبون يدويون)

خادم Node.js واحد بلا أي مكتبات خارجية (Node 18+). يقدّم الصفحات الثلاث ويزامنها لحظياً عبر SSE.

| الصفحة | الرابط | المستخدم |
|---|---|---|
| المقدم | `/` | جهاز المقدم (يُنشئ الجلسة ويعرض رمز QR) |
| شاشة العرض | `/s/CODE` | الشاشة الكبيرة (زر «افتح شاشة العرض» في اللوبي) |
| اللاعب | `/j/CODE` | الجوال — هذا هو الرابط المشفّر داخل رمز QR |

رمز QR يُولَّد في متصفح المقدم من `location.origin + '/j/' + CODE`، أي أنه يحمل **عنوان موقعك أنت** وليس claude.ai.

## الاختبار محلياً
```
node server.js            # المنفذ 3000 (أو PORT=8080)
node test.js              # اختبارات API
```
افتح `http://localhost:3000`. للجوالات على الشبكة نفسها افتح صفحة المقدم عبر عنوان جهازك (مثل `http://192.168.1.20:3000`) ليحمل الرمز هذا العنوان.

## النشر العام (مجاني تقريباً) — مثال Render
1. أنشئ مستودع GitHub وارفع محتوى هذا المجلد.
2. render.com ← New ← **Web Service** ← اختر المستودع.
3. Runtime: Node · Build Command: (اتركه فارغاً) · Start Command: `node server.js`
4. بعد النشر تحصل على رابط مثل `https://your-game.onrender.com` (HTTPS تلقائياً).
5. افتح هذا الرابط على جهاز المقدم ← «ابدأ اللعبة» ← سيظهر رمز QR يشير إلى `https://your-game.onrender.com/j/CODE`.

يعمل الشيء نفسه على Railway وFly.io وأي VPS (`node server.js` خلف HTTPS). متغيرات اختيارية: `PORT`، `MIN_PLAYERS` (الأدنى لكل فريق، الافتراضي 3).
ملاحظة: الخطة المجانية قد «تنام» بعد خمول؛ افتح الرابط قبل الفعالية بدقائق. الجلسات محفوظة في ذاكرة الخادم (تضيع عند إعادة تشغيله).

## اللاعبون بلا جوال
من اللوبي اكتب الاسم في خانة «إضافة لاعب بلا جوال» لكل فريق (✋). يمكنك تعديل الاسم ✎ أو نقله ⇄ أو حذفه ✕ قبل البدء. أثناء اللعب تظهر خانات «إجابة نيابةً عنه» (سبوركل)، وأزرار المزايدة/الانسحاب/إضافة الإجابات (تحدي الثلاثين)، و«تسجيل ضغطة نيابةً» (خمن العبارة). ولاعب أُضيف يدوياً يستطيع لاحقاً فتح رابط QR واختيار اسمه من القائمة لربط جواله دون تكرار.

## حدود يجب معرفتها
- ضغطة الجوال تُرتَّب بترتيب وصولها للخادم (الخادم هو الحكم). ضغطة المقدم نيابةً عن لاعب تُسجَّل لحظة نقر المقدم وتُعلَّم «يدوية»، فهي **ليست بدقة** ضغطة الجوال.
- الأسئلة والألغاز (٣+٢ سبوركل، ٣ تحدي الثلاثين، ٨ ألغاز) محتوى مبدئي كتبته دون بحث ويب؛ راجعها في أعلى `server.js` أو أضف أسئلتك.
- لم يُختبر على جوالات حقيقية ولا على استضافة عامة في بيئة التطوير، بل بمتصفحات منفصلة على localhost.
